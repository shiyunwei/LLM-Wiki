# 原始文獻存放區 (Raw Sources)

請將欲處理的學術論文原始 PDF 檔案放置於此目錄。

* **原則**：此目錄下的檔案為「不可變的事實來源（Truth of Source）」，Agent 僅會讀取，絕不會修改或刪除裡面的檔案。
* **命名建議**：建議採用 `YYYY-paper-title.pdf`（例如：`2017-attention-is-all-you-need.pdf`）。
* **使用方式**：將 PDF 放入此處後，直接對 Agent 下達指令：
  * 「請讀入 `raw/xxx.pdf`」
  * 或「請批次處理 `raw/` 底下所有尚未入庫的論文」
